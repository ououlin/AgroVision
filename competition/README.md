## 审计发现

1. 当前 `yolo11n.onnx` 实际是 MobileNetV3-Small 分类模型，不是 YOLO 检测模型。
2. ONNX 输入为 `[1,3,224,224]`，输出为 `[1,38]`，支持 PlantVillage 38 类。
3. 38 类 color 数据已完成 54,305 张归档、固定划分和测试指标记录。
4. 当前模型测试集 Top-1 为 99.1808%，Top-3 为 99.9511%，仅代表 PlantVillage 域内结果。
5. 现有百科与标签目录覆盖更广，但知识覆盖不等于模型识别能力。
6. 当前演示 APK 为 2.0.0 Debug v2 签名包，SHA-256 已写入模型与发布文档。

## 使用顺序

1. 先填写 `06_submission/MATERIAL_CHECKLIST.md` 顶部的报名信息。
2. 完成报名表及承诺书签字盖章，合并为不超过 10 MB 的 PDF。
3. 复核 `01_project/农智眼AgroVision项目说明书_盲审版.pdf` 的匿名内容。
4. 使用最终 APK 录制不超过 3 分钟的 MP4 应用案例视频。
5. 按“赛道编号+作品名称+单位或队伍名.zip”命名并通过大赛官网提交。

总方案见 `../docs/COMPETITION_PLAN_2026.md`，详细数据许可台账见 `../docs/DATA_PROVENANCE.md`。
