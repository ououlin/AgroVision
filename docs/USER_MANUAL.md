# 农智眼 AgroVision 用户使用说明书

> 适用版本：AgroVision 2.0.0（38 类比赛模型构建）  
> 更新日期：2026-08-11
>
> 适用对象：果园种植户、农技人员、基地管理员、巡检人员、合作社及农业相关从业者

---

## 1. 产品简介

**农智眼 AgroVision** 是一款面向农业生产场景的智能识别与辅助诊断应用。用户可通过拍照或选图快速识别作物病虫害，并获取对应的百科知识、AI 分析和防治建议。

### 1.1 适合什么场景

- 田间巡查时快速判断病虫害
- 果园、菜地、温室的日常病害排查
- 农技人员现场辅助诊断
- 记录病害发生过程，便于后续复盘
- 查看农药、肥料包装文字信息

### 1.2 核心能力

- **病虫害识别**：使用 38 类本地模型拍照、相册选图或开启实时识别
- **问诊结果**：按“今天先做、原因、用药参考、复查时间”组织建议
- **问农技**：支持日常对话、一般问题与农业知识问答
- **病虫百科**：查看病虫害详情与防治信息
- **历史记录**：保存历次识别结果，便于回看
- **农事管理**：查看种植概览，管理地块、作物、识别记录与用药记录
- **农技搜索**：离线检索病虫百科、症状、防治和用药知识
- **植保用药**：选择病虫害与有效成分，按产品标签计算配药量，并整理农资采购清单
- **农情顾问提醒**：基于物候、天气和用药安全间隔期提供本地提醒
- **数据统计**：查看识别趋势与病害分布
- **数据备份**：导出/导入本地历史、反馈、地块与用药记录

> OCR、GIS 地图、巡检任务、告警中心、系统监控、巡检机器人属于实验或 V3.0 模块，2.0.0 默认不开放。

当前识别模型覆盖 PlantVillage 的 38 个健康/病害类别和 14 种作物。模型基于受控背景叶片图片训练，真实田间照片可能因光照、背景、遮挡和拍摄距离产生误差。

### 1.3 使用原则

- 识别结果仅作为辅助参考，不替代人工经验判断
- 用药前请务必结合当地农业规范和产品说明书
- 复杂病情建议结合农技人员意见处理
- 图片越清晰，识别结果通常越准确

## 2. 安装与首次启动

### 2.1 安装方式

请按照项目发布方式安装应用，或由管理员统一部署到设备。

### 2.2 首次打开需要授权什么

应用只会在对应功能由您主动触发时请求以下权限：

- **相机权限**：用于拍照识别
- **粗略定位权限**：用于获取当前城市天气
- **通知权限**：添加用药记录后，用于安全间隔期和采收提醒

从相册选图使用系统文件选择器，不需要相册或存储权限。如果只使用离线问答、百科或农技搜索，可以不授予以上权限。

### 2.3 第一次使用建议

1. 在首页点击「拍照问诊」
2. 按用途说明授予相机权限
3. 拍一张光线充足、异常部位清晰的照片
4. 查看“今天先做”和安全提醒
5. 如需长期管理，再到「农事」创建地块并记录用药

如果当前版本开放了实验能力，还可能看到：

## 4. 首页怎么用

首页是应用的总入口，主要用于快速进入各功能模块。

### 4.1 首页可看到什么

- 拍照问诊主入口
- 今日天气与巡田建议
- 今日农事与复查提醒
- 最近识别记录
- 常用功能快捷入口

### 4.2 常用入口

- **拍照问诊**：拍摄作物异常部位
- **相册问诊**：从相册选择照片
- **病虫百科**：查看病虫害知识
- **问农技**：咨询农业问题或进行日常交流
- **历史记录**：查看过去的识别结果
- **农事**：创建地块、查看地块详情、登记用药
- **农技搜索**：无需 API Key 的本地检索入口

### 4.3 使用建议

如果您是第一次使用，建议按这个顺序体验：

1. 先试一次拍照识别
2. 再打开识别结果页查看详情
3. 进入病虫百科比对知识
4. 创建地块并绑定后续识别/用药记录
5. 最后使用 AI 助手追问具体问题

## 5. 拍照问诊使用说明

这是本应用最常用、也是最核心的功能。

### 5.1 支持的识别方式

- **拍照问诊**：对准作物异常部位直接拍照
- **相册问诊**：选择手机中的现有照片
- **实时识别**：点击底部“实时”按钮，画面稳定时自动更新候选结果

### 5.2 拍照识别步骤

1. 进入「问诊」
2. 从顶部作物菜单选择当前作物
3. 将叶片或病斑放入中央取景框
4. 尽量让目标区域居中、清晰
5. 点击中央拍照按钮
6. 等待本地模型识别
7. 查看识别结果和建议

作物菜单包含苹果、蓝莓、樱桃、玉米、葡萄、柑橘、桃、辣椒、马铃薯、树莓、大豆、南瓜、草莓和番茄。选对作物可以过滤不相关类别。

### 5.3 相册识别步骤

1. 从首页点击「相册问诊」
2. 点击相册按钮
3. 选择一张清晰图片
4. 等待系统分析
5. 查看识别结果

### 5.4 提高识别准确率的建议

为了让识别更准确，请尽量做到：

- 光线充足，不要太暗
- 病斑或虫害特征占画面较大比例
- 尽量对焦清晰，避免模糊
- 同一问题建议拍 2～3 张不同角度图片
- 避免背景杂乱，减少干扰
- 如果是叶片病害，尽量拍叶片正反面特征

### 5.5 识别结果怎么看

识别完成后，通常会显示：

- 病虫害名称
- 判断程度，例如“较确定”或“需要补拍确认”
- 严重程度
- 简要说明
- 推荐防治建议
- 进入百科详情的入口

### 5.6 如果结果看起来不对怎么办

可以尝试：

- 重新拍一张更清晰的照片
- 换一个角度再识别
- 把病斑拍得更近一些
- 到百科里查看相近病害进行对比
- 使用 AI 助手进一步提问

## 6. 问诊结果与处理建议

识别完成后，结果页面会直接整理处理建议，必要时可以继续进入“问农技”追问。

### 6.1 结果页通常显示什么

- 识别图片预览
- 病虫害名称
- 判断程度
- 严重程度
- 今天先做什么
- 用药参考和安全提醒
- 复查时间
- 收藏、分享、重新识别等操作入口

### 6.2 AI 诊断能做什么

AI 诊断会基于识别结果生成结构化建议，通常包括：

- 今天先做什么
- 可能原因和判断依据
- 处理建议
- 用药参考
- 复查时间
- 日常管理建议

### 6.3 在线与离线模式

- **在线模式**：网络可用时，问农技内容通常更详细
- **离线模式**：可使用本地规则或知识库生成基础问诊建议

> 如果网络不稳定，建议先使用离线诊断，再结合百科查看。

## 7. 我的农场怎么用

V2.0 新增「我的农场」能力，用于把零散识别记录组织成可复盘的地块档案。

### 7.1 创建地块

1. 在底部导航点击「农事」
2. 点击右下角「新建地块」
3. 填写地块名称、作物类型、面积、物候期和备注
4. 经纬度为可选项，不填写也可以保存

### 7.2 查看地块详情

农事首页会先显示地块数、总面积、作物种类、物候记录和定位完成情况。每张地块卡片展示作物、物候期、面积、定位及本地/同步状态。

地块详情页可查看：

- 地块基础信息
- 关联的识别历史
- 用药记录时间线
- 安全间隔期与预计采收信息

### 7.3 添加用药记录

1. 进入某个地块详情
2. 点击添加用药
3. 填写药剂名称、用量、施用日期、安全间隔期
4. 如有采收计划，可填写预计采收日期

添加后，系统会在本地通过 WorkManager 扫描即将到期的安全间隔期和采收提醒。提醒是否弹出还取决于系统通知权限。

### 7.4 植保用药与配药计算

1. 从首页「植保用药」、病虫详情或问诊结果进入
2. 选择病虫害和一种备选有效成分；多个推荐成分表示轮换或备选，不表示可以直接混用
3. 按手中产品登记标签填写每亩用量，再填写面积、亩用水量和药箱容量
4. 查看总药量、总用水、配药桶数、整桶和最后一桶用量
5. 可进入农资商城查看匹配商品并加入采购清单，也可把结果带入地块用药记录

商城为本地展示目录，价格仅供演示，不提供在线支付。实际购买和使用前必须核对农药登记证、登记作物、防治对象、剂型、有效成分含量和安全间隔期。

### 7.5 使用建议

- 每个真实地块建议单独创建一条档案
- 用药记录尽量当天填写，便于后续追溯
- 安全间隔期仅作提醒，实际用药和采收必须以农药标签与当地农技规范为准

## 8. 农技搜索怎么用

农技搜索是 V2.0 新增的离线检索入口，和 AI 助手不同：它不调用大模型，不需要 API Key，直接检索本地病虫百科和知识库。

### 8.1 适合搜索什么

- 病虫害名称，例如“黑星病”“红蜘蛛”
- 症状描述，例如“黄叶”“卷叶”“叶片斑点”
- 防治问题，例如“白粉病怎么治”“用什么药”
- 拼音首字母，例如“hxb”可匹配“黑星病”相关内容

### 8.2 检索能力

- 支持农业口语同义词，如“打药/喷药/用药”
- 支持拼音首字母兜底匹配
- 会根据问题意图调整结果，例如症状、原因、防治、药剂
- 返回内容来自本地百科，离线可用

### 8.3 与“问农技”的区别

- 农技搜索：检索式、离线、结果更稳定
- 问农技：可结合对话历史和农场摘要，适合追问和日常交流

## 9. 问农技怎么用

“问农技”可进行日常对话和一般问题交流，同时针对病害防治、施药建议、种植管理等农业问题结合本地知识库。

### 9.1 使用步骤

1. 从首页点击「问农技」，或在问诊结果点击「继续问农技」
2. 在输入框输入您的问题
3. 点击发送
4. 查看系统回复
5. 如有需要继续追问

### 9.2 推荐提问方式

问题越具体，回答通常越有帮助。比如：

- “番茄叶片出现褐色斑点，怎么判断是什么病？”
- “苹果树落叶严重，可能是什么原因？”
- “白粉病一般怎么防治？”
- “喷药后多久适合复查？”

### 9.3 离线情况下能否使用

可以。本地助手支持问候、感谢、能力询问等基础交流，并可通过本地知识库回答农业问题。

### 9.4 农场摘要上下文

如果已经创建地块、用药记录或识别历史，AI 助手会在本地生成农场摘要，用作回答上下文。例如询问“这个阶段该注意什么”，系统会优先结合地块作物、近期病害和用药记录进行回答。

## 10. 病虫百科怎么用

病虫百科是一个可查询的农业知识库，适合用来快速了解病虫害的基础信息。

### 10.1 可以查看什么

- 中英文名称
- 基本简介
- 典型症状
- 传播方式
- 发病原因
- 防治建议
- 推荐药剂
- 恢复周期
- 与当前模型类别准确匹配的真实叶片示例图

原始知识库中的条目如果暂时没有准确图片，会先从 App 的百科列表和搜索结果中隐藏；当前 App 展示 26 个有真实 PlantVillage 示例图的条目，避免用错误病害图片误导判断。

### 10.2 使用方法

1. 进入「病虫百科」
2. 在搜索框输入病虫害名称
3. 根据作物分类筛选
4. 点击条目查看详情

### 10.3 适合什么场景

- 不确定识别结果时进行人工比对
- 了解某个病害的典型症状
- 查询防治建议和常见用药思路
- 给农技人员、合作社成员做知识参考

## 13. OCR识别说明

OCR 功能代码和 ML Kit 依赖已保留，但 2.0.0 默认不开放入口。该能力用于识别包装或说明书上的文字信息，常用于农药、肥料等农业物资。

### 13.1 适合识别什么

- 农药说明书
- 肥料包装
- 农资标签
- 使用说明或成分说明

### 13.2 使用步骤

1. 进入 OCR 页面
2. 选择识别类型
3. 拍照或选图
4. 点击开始识别
5. 查看提取出的文字或结构化信息

### 13.3 拍摄建议

- 保证文字完整
- 避免反光
- 避免折痕遮挡
- 尽量拍清楚小字

> 注：该功能属于实验入口，是否显示取决于 `FeatureFlag.isOcrEnabled`。

## 16. 常见问题

### Q1：没有网络可以用吗？

可以。基础识别、百科查询和历史记录通常可离线使用；在线 AI 问答和高级诊断则可能需要网络。

### Q2：识别不准怎么办？

建议先检查：

- 图片是否清晰
- 是否对焦准确
- 光线是否足够
- 病斑特征是否明显
- 拍摄角度是否合适

必要时重新拍照识别。

### Q3：如何提高识别效果？

- 拍近一点
- 让病斑占画面更大比例
- 多拍几张对比
- 避免背景干扰
- 尽量拍摄典型症状部位

### Q4：AI 助手回答不够完整怎么办？

可能是因为：

- 当前网络不稳定或在线服务不可用
- 问题描述太笼统
- 当前知识库覆盖有限

建议把问题说得更具体一些。

### Q5：数据会丢失吗？

如果数据只保存在本机，卸载应用、清除数据或设备重置都可能导致数据丢失。V2.0 支持导出/导入本地备份，建议定期备份。云同步需要部署后端并登录后才能完整使用。

### Q6：为什么有些功能看不到？

因为部分功能属于扩展模块，是否显示取决于版本和功能开关配置。

### Q7：为什么没有病斑框？

当前随包 MobileNetV3-Small 是图像分类模型，只返回整张图片的候选类别和置信度，不输出病斑位置框。独立害虫目标检测模型尚未随包发布。
