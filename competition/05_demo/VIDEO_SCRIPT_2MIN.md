# 初赛 2 分钟视频脚本

> 只使用最终比赛 APK 和真实测试数字。当前模型重训前先用于排练，不录正式版。

| 时间 | 画面 | 旁白要点 | 所需材料 |
|---|---|---|---|
| 0:00-0:12 | 农户巡田、叶片异常、弱网图标 | 小农户判断难、农技服务距离远、记录不连续 | 真实或授权场景图 |
| 0:12-0:25 | 数据来源与闭环图 | 融合公共数据、农技知识和田间记录，AI 只是其中一个环节 | 数据源图、来源名称 |
| 0:25-0:40 | 创建/打开地块 | 系统记住作物、物候、历史和用药 | 最终演示地块 |
| 0:40-1:02 | 飞行模式拍照问诊 | 图片在设备本地推理，展示 Top-3 和低置信度策略 | 最终模型、飞行模式 |
| 1:02-1:20 | 行动式结果 | 今天先做、原因、用药参考、复查和安全提醒 | 真实结果页 |
| 1:20-1:36 | 记录用药与采收提醒 | 处置被结构化记录，自动计算安全间隔期 | 用药记录 |
| 1:36-1:48 | 复查反馈 | 结果回流，形成可追溯闭环 | 前后对比案例 |
| 1:48-2:00 | 指标与价值 | 展示实测模型、性能、用户任务结果和跨境协同价值 | 3 个最强实测数字 |

## 录制检查

- [ ] 总时长不超过 2 分钟。
- [ ] 文件名符合“组别+参赛编号+testVideo”。
- [ ] 不出现 API Key、手机号、定位坐标和真实个人信息。
- [ ] 不展示实验入口或未完成页面。
- [ ] 所有数字与测试报告一致。
- [ ] 有一份无旁白字幕版和一份原始录屏备份。
