# AgroVision 2.0.0 上线检查清单

> 检查日期：2026-08-11  
> 目标版本：`versionName=2.0.0`，`versionCode=20000`

## 当前发布范围

- 开放：拍照/相册问诊、问农技、百科、历史、农事地块、植保配药、农资展示目录、采购清单、用药记录、农技搜索、农情提醒、手动备份。
- 降级：未配置第三方 LLM API Key 时，AI 助手使用本地会话与农业规则；缺少害虫 ONNX 资产时退回病害单头模型。
- 关闭：手机号账号、云同步、OCR、GIS、巡检、告警、机器人、开发者中心。

## 已完成的代码门禁

- [x] Room 使用完整 1 -> 5 迁移，不允许缺失迁移时清空数据库。
- [x] Release 禁止明文 HTTP；本地 HTTP 白名单只存在于 Debug 资源。
- [x] Release 产物缺少正式 keystore 时构建失败，禁止 debug 签名包流出。
- [x] 后台提醒在隐私同意后注册，并使用 Hilt WorkManager Factory。
- [x] 移除电话状态、相册和存储权限；通知权限在添加用药记录后按场景申请。
- [x] 关闭系统自动云备份；API Key 和 Token 使用加密 SharedPreferences。
- [x] 关闭未部署的账号/云同步入口及 Release 开发者中心。
- [x] ONNX 推理输入张量和输出结果均在每次推理后关闭。
- [x] 农户主导航改为“首页/问诊/农事/我的”，普通流程隐藏模型与 API 技术术语。
- [x] 问诊结果按行动、原因、用药参考、复查和安全提醒组织，并支持带上下文继续问农技。
- [x] 38 类 MobileNetV3-Small ONNX、标签和元数据已集成，模型 SHA-256 已归档。
- [x] AI 视觉识别页面已重构为顶部状态、作物选择、取景框和底部控制台。
- [x] 农事页面已增加种植概览及地块面积、物候、定位、同步状态。
- [x] 植保用药支持标签剂量计算、分桶配比、农资目录、采购清单及地块用药记录预填。
- [x] Debug APK 已构建并通过 v2 签名校验，SHA-256 为 `8CF551F3CCA6E1B1B11516B57460C58F7FB409CE0C355FF222263D40D586FE86`。

## 暂不开放功能的解锁条件

- 账号：生产域名可解析、短信通道可用、限流/风控完成、服务端账号删除闭环、渗透测试通过。
- 云同步：服务端接口与客户端契约联调通过，冲突策略、幂等、断网重试、换机恢复和隐私披露验收完成。
- 害虫检测头：`pest_detector.onnx`、标签和温度参数随包发布，并通过真实田间图像验收。

## 发布后值守

- [ ] 首发采用小流量发布，准备一键下架/回滚说明和上一稳定包。
